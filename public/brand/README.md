# Fleet Fusion — Brand Pack

Fleet Fusion is a smart assistant for trucking companies. It spots when a delivery is running late, works out how much money that lateness will cost, and suggests the cheapest way to fix it.

Open `fleet-fusion-brand-pack.html` for the full guidelines (works offline).

## Logo
Two routes merge into a stop: the plan (Cobalt) and reality (Ink) brought back together at the cheapest point.

- Grid 48 × 48u · stroke 5.5u round caps · stop dot Ø 9u
- Clear space: 18u (2× dot) on all sides
- Minimum size: lockup 96px / 24mm · mark 16px / 5mm
- Don't rotate, stretch, recolour, outline or add effects.

> Lockup SVGs use live Archivo text. Outline the text in a vector editor before sending to print.

- **Archivo** — display and body (Bold, width 100–115%)
- **IBM Plex Mono** — data, ETAs, costs, labels

Both free on Google Fonts (OFL).
